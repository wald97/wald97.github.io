## Énoncé du challenge

>### DEPPIX
>
>Un passager a publié une photo de son billet d’avion en ligne.  
>Le billet est fortement pixelisé, mais certaines informations clés restent partiellement récupérables.
>
>Votre tâche consiste à identifier :
>- Le prénom et le nom du passager  
>- Le numéro de siège  
>- Le code IATA de l’aéroport d’arrivée  
>
>**Format du flag :**  
>`OSINT{Prenom_NOM_SIEGE_IATA}`
>

## Démarche OSINT

Le code barre peut se lire avec en ligne avec l'outil [**online barcode reader**](https://online-barcode-reader.inliteresearch.com/).

<figure>
  <img src="/assets/img/osint.industries/depix/inlite0.jpg" alt="Selection fichier et code barre">
</figure>

## Analyse du résultat

- Observation de la zone **MRZ / code-barres** encore lisible.
- Lecture partielle du nom : `CHEN / MICHAEL`.
- Identification du siège : `3D`.
- Recherche du code IATA visible : `PVG`.
- Vérification du code IATA : PVG = Shanghai Pudong International Airport.
