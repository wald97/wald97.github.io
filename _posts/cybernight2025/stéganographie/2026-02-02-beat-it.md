## Démarche Stéganographie

### Observation initiale

- L’image contient des **formes noires répétées**
- La référence à la **musique** est évidente
- Les formes rappellent des **codes scannables**

En combinant les mots-clés :
- `code`
- `scan`
- `music`

On tombe rapidement sur les **Spotify Codes**.

  <img src="/assets/img/cybernight2025/steganographie/spotify_hint.png.jpg" alt="Ressemblance avec des Spotify Codes">
</figure>

---

### Comprendre les Spotify Codes

Sources utiles :
- Blog explicatif : <https://boonepeter.github.io/posts/2020-11-10-spotify-codes/>
- Documentation officielle Spotify

Un Spotify Code valide :
- Contient le **logo Spotify à gauche**
- Est composé de **23 barres**
- Les barres aux extrémités sont **plus petites**
- Est [**scannable uniquement via l’application Spotify**](https://www.spotify.com/fr/download/)

---

### Extraction des codes

- L’image contient **plusieurs codes imbriqués**
- Ils doivent être **séparés individuellement**
- On identifie **7 codes distincts**

Chaque code scanné dans Spotify donne un titre :

1. **Cybernight** – HYPERON  
2. **FLAG** – Ichiko Aoba  
3. **Is** – Hel  
4. **Newb** – Perfect Plush  
5. **Corp** – Black Thunder  
6. **For the win** – Thomas Bergersen (Two Steps From Hell)  
7. **Skibidi** – Little Big
